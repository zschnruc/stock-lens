# 看盘终端 · Stock Viewer

一个**零部署、双击即用**的纯前端看盘工具：输入股票名称或代码即可查看 K 线，支持自选股收藏，覆盖 A 股、港股、美股。

## 功能特性

- **股票搜索与联想**：输入名称或代码（如 `茅台` / `600519` / `腾讯` / `AAPL` / `00700`），实时返回候选；支持 `↑` `↓` `Enter` `Esc` 键盘操作。
- **K 线图表**：蜡烛图展示开高低收，悬浮十字光标查看当日明细，滚轮 / 滑块缩放。
- **周期切换**：日 K / 周 K / 月 K 一键切换。
- **技术指标**：MA5 / MA10 / MA20 均线 + 成交量柱状图，可勾选显隐。
- **自选股收藏**：一键加自选 / 移除，右侧列表快速切换，数据保存在浏览器本地（`localStorage`），关闭重开仍在。
- **三市场覆盖**：A 股（沪深 / 科创板 / 北交所）、港股、美股；红涨绿跌（A 股习惯）。
- **网络异常兜底**：接口不可达时自动降级为标注清楚的演示数据，不白屏，可一键重试真实数据。

## 快速开始

**无需安装、无需构建、无需后端。**

直接用浏览器双击打开 `index.html`（`file://`）即可运行；也可以用任意静态服务器托管。

需要联网：图表库（ECharts CDN）和行情接口都依赖网络。首次加载稍等片刻即可看到默认股票（贵州茅台）的 K 线。

> **提示**：在受限网络环境（如某些内置预览面板、内网、代理后）无法访问行情接口时，页面会显示标注"· 演示数据"的模拟 K 线，并非真实行情。此时请用系统浏览器直接打开 `index.html`，在能访问外网的环境下即可拉取真实数据。

## 使用示例

1. 打开页面，默认展示贵州茅台日 K。
2. 在搜索框输入 `茅台`，从候选中选中，查看其 K 线。
3. 点击 `周K` 看趋势，勾选 / 取消 MA 均线与成交量。
4. 点击 `☆ 加自选` 收藏，下次打开在右侧自选列表一点即达。
5. 输入 `AAPL` 或 `00700` 可查看美股、港股标的。

## 技术栈

| 层面 | 选择 |
| --- | --- |
| 页面 / 样式 / 逻辑 | 原生 HTML5 + CSS + ES6 JavaScript（无框架、无构建） |
| 图表 | ECharts 5.x（CDN 引入） |
| 行情数据 | 腾讯证券公开接口（HTTPS + 变量赋值式 JSONP，绕过 `file://` 跨域限制） |
| 数据存储 | 浏览器 `localStorage` |

行情接口：`smartbox.gtimg.cn`（搜索联想）、`web.ifzq.gtimg.cn`（K 线，前复权）。数据层与上层解耦，接口变更时只需替换数据层。

## 已知限制

- 展示的是**历史 K 线**（前复权），头部价格取自最新一根 K 线收盘价，非实时逐笔行情，盘中不刷新。
- 自选股仅存于当前浏览器本地，不跨设备同步；清除浏览器数据会丢失。
- 行情为第三方公开接口，可能因网络环境或对方策略变化而失效（已有降级方案）。
- A 股接口未提供成交额，按 `收盘价 × 成交量 × 100` 估算。
- 美股字母代码对应多个交易所，回车直达时取搜索首项，推荐从搜索候选选择。
